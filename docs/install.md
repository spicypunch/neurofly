# NeuroFly 다운로드와 설치

이 미리보기 배포본은 **Apple Silicon(M1 이상), macOS 15 이상**에서 실행합니다.
Intel Mac과 Windows용 실행 파일은 포함하지 않습니다.

## 설치

1. [GitHub 릴리스](https://github.com/spicypunch/neurofly/releases/tag/v0.2.0)에서
   `NeuroFly-0.2.0-macos-arm64.zip`을 내려받습니다. GitHub가 자동으로 제공하는
   `Source code` 파일은 앱 실행 파일이 아닙니다.
2. ZIP의 압축을 풀고 안에 있는 `NeuroFly.app`을 `응용 프로그램` 폴더로 옮깁니다.
3. `NeuroFly.app`을 엽니다. 큰 창 없이 펫과 메뉴 막대의 🪰 아이콘으로 시작합니다.
   처음에는 신경망 데이터 검증과 반응 보정에 시간이 걸릴 수 있습니다.

두 뇌 모델의 데이터와 Metal 계산 코드가 포함되어 있습니다.
앱 실행에 Xcode, Python, 추가 데이터 다운로드나 인터넷 연결은 필요하지 않습니다.

## 첫 실행 시 macOS가 차단하는 경우

현재 배포본은 **ad hoc 서명이며 Apple 공증을 받지 않은 미리보기 앱**입니다.
다운로드한 앱을 처음 실행하면 개발자를 확인할 수 없다는 경고가 나타날 수 있습니다.

앱을 한 번 열려고 시도한 뒤, 이 저장소에서 받은 앱임을 확인하고 실행하려면:

1. `시스템 설정 → 개인정보 보호 및 보안`을 엽니다.
2. 아래쪽의 NeuroFly 차단 안내에서 `그래도 열기`를 선택합니다.
3. 확인 창에서 `열기`를 선택합니다.

이는 Apple이 안내하는 앱별 예외 처리입니다. 회사에서 관리하는 Mac에서는 허용되지 않을 수 있습니다.
앱이 손상되었다는 알림이나 악성 소프트웨어 경고가 나오는 경우에는 실행을 멈추고 파일을 다시 확인하세요.
자세한 안내는 [Apple의 Mac 앱 안전하게 열기](https://support.apple.com/ko-kr/102445)를 참고하세요.

확인된 개발자로 배포하려면 **Developer ID Application 서명과 Apple 공증**이 필요합니다.
현재 ZIP에는 이 절차를 적용하지 않았습니다.
[Apple의 Developer ID 배포 안내](https://developer.apple.com/developer-id/)에서 요구 사항을 확인할 수 있습니다.

## 사용

- 메뉴 막대의 🪰에서 바나나·베리를 선택하고 화면에 먹이를 놓습니다.
- `⌘B`: 상태 창 · `⌘L`: 실험실 · `⌘P`: 일시정지/다시 시작 · `⌘Q`: 종료.
- 상태 창에서 개체, 뇌 모델, 먹이 기억 학습을 선택합니다. 최대 4개체를 지원합니다.
- 상태 창과 실험실을 닫아도 펫은 계속 실행됩니다.

앱은 모델 선택과 개체별 학습 기억을 `~/Library/Application Support/NeuroFly/colony-v1.json`에 저장합니다.
먹이 위치·몸 상태·신경망 막전압은 저장하지 않습니다.

## 파일 확인

릴리스의 `.zip.sha256` 파일을 ZIP과 같은 폴더에 내려받고 터미널에서 확인할 수 있습니다.

```sh
shasum -a 256 -c NeuroFly-0.2.0-macos-arm64.zip.sha256
```

이 검사는 다운로드 파일이 게시된 파일과 같은지 확인합니다. Apple 공증을 대신하지 않습니다.

배포 폴더의 `Licenses`에 데이터 출처와 원 코드 고지를 포함했습니다.
FlyWire 데이터는 **CC BY-NC 4.0**, Male CNS 데이터는 **CC BY 4.0**입니다.
두 데이터를 함께 포함한 이 앱은 FlyWire 데이터의 비상업적 이용 조건도 따릅니다.

이 앱은 실제 연결 데이터에 단순화한 신경 계산, 허기·연합 기억 규칙과 2D 몸체를 결합한 실험입니다.
생물학적 뇌 전체나 실제 비행을 완전히 재현한 모델은 아닙니다.
